# GiftSquad Web

Sitio de presentación de GiftSquad, la app para iPhone que sirve para coordinar regalos sin spoilers.

Publicado en https://giftsquad.web.app

## Tecnologías

- React + Vite
- React Router
- Firebase Hosting

## Comandos

```bash
npm install                      # instalar dependencias
npm run dev                      # servidor local
npm run build                    # generar la versión de producción en dist/
firebase deploy --only hosting   # publicar
```

## Estructura

- `src/pages`: páginas (inicio, privacidad y términos)
- `src/components`: componentes reutilizables
- `src/idiomas`: textos en español e inglés
- `public/screenshots`: capturas de la app
